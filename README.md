# NovaTech – Rəqəmsal Həllər

## Layihə haqqında

**NovaTech** HTML5, CSS3 və JavaScript istifadə edilərək hazırlanmış müasir və responsiv veb sayt nümunəsidir. Layihənin məqsədi təmiz kod strukturu, istifadəçi dostu interfeys və müxtəlif ekran ölçülərinə uyğun responsiv dizayn təqdim etməkdir.

---

## İstifadə olunan texnologiyalar

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Flexbox
- CSS Grid
- Media Queries
- Responsive Web Design

---

## Layihənin funksiyaları

- Responsiv Header və Naviqasiya
- Mobil cihazlar üçün Burger Menu
- Hero Bölməsi
- Haqqımızda Bölməsi
- Statistik Kartlar
- Qalereya
- Əlaqə Formu
- Footer

---

## Semantic HTML

Layihədə SEO və əlçatanlığı artırmaq üçün semantic HTML elementlərindən istifadə edilmişdir.

İstifadə olunan elementlər:

- `header`
- `main`
- `section`
- `nav`
- `footer`
- `form`
- `label`
- `input`
- `textarea`
- `button`

---

## Responsiv Dizayn

Layihə müxtəlif ekran ölçülərinə uyğun hazırlanmışdır.

İstifadə olunan texnologiyalar:

- **CSS Flexbox** – Header, About bölməsi və digər elementlərin yerləşdirilməsi üçün.
- **CSS Grid** – Qalereya hissəsində kartların responsiv düzülməsi üçün.
- **Media Queries** – Mobil ekranlarda uyğun görünüş təmin etmək üçün.
- **Burger Menu** – Kiçik ekranlarda naviqasiyanın açılıb-bağlanması üçün JavaScript istifadə edilmişdir.

---

## JavaScript funksionallığı

Layihədə aşağıdakı JavaScript funksiyaları həyata keçirilmişdir:

### Burger Menu

- Menyunun açılıb-bağlanması
- Link seçildikdən sonra menyunun avtomatik bağlanması

### Əlaqə Formu

Client-side validation tətbiq edilmişdir.

- Boş sahələrin yoxlanılması
- `preventDefault()` ilə səhifənin yenilənməsinin qarşısının alınması
- İstifadəçiyə xəbərdarlıq (`alert`) mesajlarının göstərilməsi
- Form məlumatlarının `console.log()` vasitəsilə konsola çıxarılması
- Form uğurla göndərildikdən sonra `reset()` funksiyası ilə sahələrin təmizlənməsi

---

## Əlçatanlıq (Accessibility)

Layihədə aşağıdakı əlçatanlıq prinsiplərinə əməl edilmişdir:

- Şəkillər üçün `alt` atributlarından istifadə olunmuşdur.
- HTML5 form validasiyası (`required`, `type="email"`) tətbiq edilmişdir.
- Semantic HTML elementlərindən istifadə edilmişdir.
- Düymələr və keçidlər klaviatura vasitəsilə istifadə oluna bilir.
